# Circle layout

Use the reviewed Vector circle composition for watchOS: the brand disc fills the circle and its central mark expands proportionally. circle.svg is copied from ../icon-circle.svg; its paths retain the original artwork. Default platform groups are hidden only on watchOS.

The watchOS overrides are native Icon Composer specializations in icon.json.
Square-platform artwork uses the unchanged default layers and positions.
The 1/0.94 compensation reverses Icon Composer’s measured watchOS layer inset.
