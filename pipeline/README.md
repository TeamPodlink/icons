# pipeline

Generation and validation for the monorepo. Sources live in
`platforms/`; everything generated is gitignored and reproduced by these
scripts.

| Script | Platform | What it does |
| --- | --- | --- |
| `validate.mjs` | any (CI) | Structural checks: meta.json schema, bundle slugs/dirs, icon.json parses, layer assets exist, size caps, recipe presence |
| `build-data.mjs` | any | Emits `apps/web/lib/platforms.gen.json` — the merged dataset the site renders |
| `build-registry.mjs` | any | Emits the shadcn registry (`apps/web/public/r/*.json`); `SITE_URL` env sets absolute URLs; asset URLs pin the current `@podlink/refraction` version |
| `sync-web-assets.mjs` | any | Copies Liquid Glass rasters + flat/badge SVGs into `apps/web/public/` (non-fatal when sources missing) |
| `build-assets.mjs` | **macOS + Icon Composer** | Renders every Liquid Glass bundle via ictool (Default + Dark), dedupes identical dark renditions by pixel compare, emits 64/128/256 WebP + 1024 PNG into `packages/refraction/assets`, writes `hasDark` back into meta.json |

The web app's `predev`/`prebuild` run data + sync + registry
automatically. Flat icons and badges are generated by
`packages/icons`' own `codegen`/`build:static` (see its scripts).

## Procedural recipes

Recipes for all-SVG-layer bundles are built with the sibling
[glass-to-LUT](https://github.com/nathangathright) checkout's two-phase
pipeline (measure → render → bake lightmap → score) and copied into
`packages/engine/recipes/<bundle-slug>.mjs`; record the final RMSE in
the bundle's meta.json entry. Two mechanical patches are applied to the
generated engine for web bundlers:

1. `/* webpackIgnore: true */` on the `import("node:zlib")` so webpack
   doesn't try to resolve a Node builtin into client bundles;
2. the import is attempted only when `process.versions.node` exists, so
   browsers go straight to `DecompressionStream` without a console error.
